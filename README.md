# CATS - Culturally Adaptive Therapy System

> **Proprietary software.** Unauthorised use, copying, modification, or distribution is prohibited. See [LICENSE](LICENSE).

A physiotherapy platform connecting patients and physiotherapists. Patients follow AI-guided exercise plans at home with live pose tracking; physios manage plans, monitor progress, and communicate remotely.

---

## Features

**Patient**
- Daily exercise plan with live camera session, MediaPipe tracks joint angles and counts reps automatically
- Posture scoring and real-time feedback per rep
- Multilingual voice coaching (English / Hindi / Urdu)
- Exercise demo videos (AI-generated per pain area and age group)
- Weekly progress reports with AI summary
- In-app messaging and scheduled video sessions with physio

**Physiotherapist**
- AI-generated therapy plan creation (streamed via SSE)
- Per-patient ROM target configuration per exercise
- Session scores, posture trends, pain log analytics
- Appointment scheduling and patient messaging
- Upload or manage exercise demo videos
